The Bewertung must be displayed as a table with exactly one row per criterion, in the following fixed order: "Ertragslage", "Haftbasis", "Liquiditätslage", "Kapitaldienstfähigkeit", "Nachhaltige Entwicklung", "Gesamtbewertung". Each row must contain the criterion name and its rating. Do not merge, omit or combine any of these rows.
Please ensure that the analysis is based solely on the data provided and adheres to the guidelines ASSESSMENT_GUIDELINE. Do not use any external data or make assumptions beyond the provided information. The analysis should be presented in a professional manner, following the structure and format outlined in the guidelines. Please do not summarize the KPIs in form of tables. For key figures, the data source is always the FINANCIAL_SUMMARY document.
If any additional figures are taken from a different provided source such as Konzernabschluss, this should be clearly marked and justified.
If any additional information is needed for the analysis, please request it clearly and concisely.
The analysis should go beyond simple descriptions of the financial figures and should include a critical evaluation of the company's financial health, performance trends, and potential risks. The evaluations MUST be supported by the data provided and should not include any speculative statements.
Please ensure that the analysis is comprehensive and provides a clear understanding of the company's financial situation.
